# Social Media HQ — safety-first refinement 28 October 2026

This change set is a **draft**, separate from the live site. It does not contact Buffer, publish anything, change social accounts, or migrate encrypted user data.

## Resolved in the branch
- The normal editor, quick-review and multi-post approval use the same media readiness checks for visually published posts: real local media references, correct profile and media metadata, consistent counts and accessible description.
- Before approval, the app attempts to decrypt/read attached images to identify missing IndexedDB records.
- Marking Published requires an actual HTTPS public post URL and the existing external-post confirmation.
- Cancelling a seven-day ZIP import displays a neutral cancellation message, never a false success.
- If post saving fails, the in-memory changed post is rolled back while the editor remains open.
- Image uploads now commit as one group, and remove the new encrypted blobs and metadata on failed image read or save.
- Permanently deleting artwork still referenced by saved/recycled posts is blocked. Empty-bin preflights referenced images.
- Posts-only, complete and pre-import restores initialize the two default profiles for legacy backup compatibility.

## Verification and non-goals
- Ad hoc V8 checks passed on multiple media, approval and deletion scenarios.
- Persistent source-based tests are in `admin/tests/hq-safety.test.mjs`; run with `node --test admin/tests/hq-safety.test.mjs` before merging.
- No full Safari/iPhone run, storage quota injection, provider calls, or production import has been performed.
- Recovery snapshots are still overwritten by the next weekly import. Versioned, per-profile history is a later improvement.
- One single `altText` still applies to all carousel images; per-image alt text is a follow-up.
- Buffer remains iPhone share-sheet/manual only, not a confirmed server-side publishing integration.
- This feature must not be merged until a full encrypted-backup and restore rehearsal and a live-device check have been completed.
